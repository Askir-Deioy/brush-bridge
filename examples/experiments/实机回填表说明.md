# 实机回填表说明

作者：askir。本软件完全免费。

请使用 `实机回填表.xlsx` 或 `实机回填表.csv`，每一行对应一支实验笔刷。建议按下面顺序填写：

1. 在原软件中打开原笔刷，填写“原笔刷 软件名”和“原笔刷 笔迹、压感、旋转、混色等”。
2. 把同一支笔刷转换后的文件导入目标软件，填写“转换笔刷 软件名”和“转换笔刷 笔迹、压感、旋转、混色等”。
3. 用“截图补充”填写截图文件名或相对路径。截图建议包含软件名称、笔刷设置面板和实际笔迹，原笔刷与转换笔刷使用相同画布、相同画笔大小和相同压力档位。
4. 把转换后的实际表现写在“实际效果”，把是否成功导入、关闭软件后重启是否仍保留写在“导入/重启结果”。
5. “预期效果”由 Brush Bridge 预先填写。实际不一致时请保留原话，不要为了通过验收而改写预期效果。

建议记录：点、慢速直线、快速直线、曲线；轻压/中压/重压；旋转方向；颗粒、双重笔刷、湿混色和颜色动态。若软件不支持某个功能，请直接写“不支持”或“未找到对应设置”。
