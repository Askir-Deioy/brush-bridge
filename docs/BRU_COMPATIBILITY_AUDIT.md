# 画世界 Pro BRU 兼容性审计

日期：2026-11-06。状态：旧版结构可读写；没有足够证据证明新版 BRU 已整体更换格式。

## 当前实现

`brush_bridge/formats/huashijie.py` 当前使用 `hsjbru` 头部、版本字段、参数记录和成对 PNG 资源。代码会解析已观察到的 protobuf 风格字段，并把未知字段和原始记录保存到 `.brushpkg` 扩展区；写出后做结构回读检查。

这说明文件结构路线可运行，但不能替代画世界 Pro 真实设备导入和笔迹验收。

## 不提前假设格式更新

新版兼容问题需要成对样本支持：同一软件版本下的基础硬圆、压力曲线、倾斜、纹理和多笔刷导出；再与旧版本或现有样本做字节和字段差异。没有样本前不先写版本探测器，也不把固定常量直接宣布为“旧版专属”。

## 需要的只读检查

未来可增加 `scripts/inspect_bru.py`，第一版只输出头部版本、声明长度、PNG 数量/尺寸、参数记录的 wire 类型和未知字段偏移。对于无法解释的字段保留原始字节，不根据字段编号猜语义。只有差分样本证明存在版本分支后，才拆成版本专用解码器/编码器。

## 验收边界

- 文件层：结构回读、资源数量和尺寸检查。
- 设备层：在指定画世界 Pro 版本导入、重启/重新打开和基础笔迹。
- 效果层：压力、倾斜、纹理、混色和多笔尖单独记录。

如果新版 BRU 暂时无法可靠写出，应明确提示并保留 `.brushpkg` 主存档；不能生成一个看似成功、实际无法使用的文件。
