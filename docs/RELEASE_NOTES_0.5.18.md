# Brush Bridge 0.5.18

## 格式修复

- 修正 Procreate 双重笔刷导出到 Photoshop 时的链接尺寸。Photoshop 不支持 Procreate 的链接尺寸字段，输出会把次笔尖直径对齐到主笔尖，避免描边笔刷被放大成实心圆。
- 修正新版画世界 Pro v8 多笔刷 `.bru` 读取。一个文件中串联的多条参数记录现在会分别显示和导出。

## 取色器

- CSP 自动同步增加鼠标/数位笔冻结时长，可选关闭、0.3、0.6、1.0 和 2.0 秒。
- 增加 Photoshop 自动同步。取色器会调用 Photoshop 的 `I` 工具取样，并在完成后切回画笔工具。

## 验证

- 179 项自动测试通过，4 项因本机未安装对应软件或样本而跳过。
- `小靳紫藤花.brushset` 读取 3 支笔刷，Photoshop ABR 输出保留描边笔刷的链接双笔尖尺寸近似。
- `测试笔刷组.bru` 读取并回写 3 支笔刷。
