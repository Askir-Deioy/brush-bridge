# Brush Bridge 维护总览

最后整理：2026-11-06。维护对象：`D:\AAAINPROVE\brush-bridge`。

## 当前事实

- 这是纯文件转换器：用户选择输入文件、目标格式和输出位置，转换流程不依赖目标软件是否安装。
- `.brushpkg` 是独立主存档；它可以保存公共参数、素材、来源快照和未知字段，再分别导出目标格式。
- 文件解析/回读、目标文件结构和真实软件导入是三层不同证据。真实导入、重启保留、压感、混色和笔迹差异必须在对应软件中单独记录。
- 0.5.3 是当前准备发布的版本。旧源码、冻结构建和历史发布目录并存。每次推送新的开发改进也要先递增版本号，让窗口标题、主存档来源和问题记录能够区分实际代码版本。

## 目录职责

| 位置 | 用途 |
|---|---|
| `brush_bridge/` | 转换核心、格式编解码器、GUI 和报告生成 |
| `tests/` | 自动回归与格式级测试；外部样本缺失时的跳过不能当通过 |
| `scripts/` | 路线、实验包、公开样本、冻结构建和实机 CSV 的验证入口 |
| `docs/` | 当前维护文档、格式说明、兼容性和证据索引 |
| `docs/feedback/` | 每次用户反馈的不可变记录；修复过程追加，不覆盖原始事实 |
| `examples/experiments/` | 可分享的原创实机测试包及回填表 |
| `.cache/` | 本地验证输出，不作为产品承诺；引用时写明文件名和生成时间 |
| `dist/`、发布目录 | 构建产物。发布前必须与当前源码重新核对 |

运行 `.venv-win\Scripts\python.exe scripts\build_exe.py` 后，可以直接打开 `build\BrushBridge\BrushBridge.exe` 做本机预览。构建脚本会把 `dist\BrushBridge` 的 `_internal` 运行时同步到这个预览目录。正式发布仍从 `dist/` 组装，不需要先做安装包验证。

当前待办目标是新版画世界 Pro BRU 的版本化读取和写出、彩色多素材目标适配、其他 Photoshop 版本的 ABR 兼容实机确认，以及长报告窗口的冻结预览确认。每次对话结束时从这四项中保留仍未完成的项目。

## 维护顺序

1. `git status --short --branch`，确认是否有未提交源码、锁文件或构建产物。
2. 读取本文件、`ISSUE_LOG.md`、`STAGE_STATUS.md` 和对应反馈记录。
3. 对新样本保存文件名、大小、修改时间、SHA-256、源/目标软件版本；商业文件只保存元数据和用户授权的必要证据，不复制进仓库。
4. 先复现并分层：解析、文件结构、真实导入、真实笔迹。修改前留下失败证据。
5. 只改能解释问题的最小范围；补有意义的回归测试或验证脚本。
6. 运行与改动匹配的测试。涉及发布时再运行冻结构建、`verify_build.py` 和 `make_release.py`。
7. 更新问题台账、反馈记录和 `STAGE_STATUS.md`；写清哪些结论仍是 `not_verified`。

## 证据等级

| 等级 | 含义 |
|---|---|
| L0 | 用户描述或截图，尚未复现 |
| L1 | 本工具能解析/回读，或文件结构检查通过 |
| L2 | 目标格式文件已生成并在目标软件中成功导入 |
| L3 | 导入后重启、基本参数和代表性笔迹已核对 |
| L4 | 多版本/多设备的真实验收，含混色、动态和复杂素材 |

L1 不得自动升级成 L2；L2 也不等于效果无损。报告中的近似、缺失资源和不可表达属性要逐项保留。

## 本次反馈的初步判断

当前可访问的 `问题笔刷导出.abr` 与 `问题笔刷导入导出.abr` 都能被解析为 v6.2、2 支笔刷；名称、尺寸、间距和笔尖像素一致。它们的文件哈希不同，但这只能说明容器中有字节差异，不能证明哪一个是 Photoshop 原生导出或哪一个一定能导入。消息里写的“未标题画笔.abr”当前下载目录没有同名文件，实际存在的候选文件需在下一次复现时明确对应关系。

C 盘差异不是首要假设：转换器按设计不查找目标软件安装位置。只有本地素材库、权限、临时目录、区域/编码或目标软件版本等环境因素可能影响结果。Photoshop 的“文件与此版本不兼容”更应先按 ABR 版本、区块结构、笔刷子类型和原生导出链路排查；必须在同一目标版本和干净用户配置下做一次实机导入，才能定根因。

`candy brush.sut` 是适合的非商业受控样本：当前读取到 1 支笔刷、11 个笔尖素材。它可以用来验证多素材笔尖的读取、主存档保存和目标格式损失报告；不能仅凭“读到 11 个素材”宣称已在 Photoshop、CSP 或其他软件中保持同样绘制效果。
