# 长期路线图

日期：2026-11-06。排序依据：转换质量、真实用户收益和单人维护成本。

## R0：当前稳定性

| 任务 | 收益 | 前置条件 | 验收 |
|---|---|---|---|
| 修复完成提示可滚动、底部按钮固定 | 客机可读完整结果 | GUI 长报告样本 | 窄窗口、长报告、取消和部分失败都可操作 |
| ABR 跨版本差分 | 解决当前高频兼容问题 | 明确来源链和 PS 版本 | 至少一组 A/B 文件在两个目标版本实机记录 |
| 文档和问题台账持续更新 | 降低交接成本 | 使用反馈模板 | 每个新问题有编号、证据和状态 |

## R1：质量优先的类别化转换

优先覆盖基础单笔尖、纹理笔、多素材/多笔尖、双重笔刷、湿混色和颜色动态。每类先定义“完整表达 / 近似 / 不支持”，再为目标格式写映射和回归样本。`candy brush.sut` 作为多素材类别的非商业起点。

验收以同一主存档分别输出多个目标格式为主，不能把一个已经降级的目标文件继续作为下一个目标的唯一来源。

## R2：小众格式独立维护

Krita、GIMP、MyPaint、SAI2、画世界 Pro 等小众路线分别放在 `docs/formats/<id>/` 和 `examples/samples/<id>/`；每个目录有自己的 README、样本清单、版本说明和实机结果。总矩阵只链接这些目录，不把稀疏样本混成一个“全部支持”结论。

只有在某个小众格式拥有可重复样本和真实用户需求时，才提升为新的正式支持级别。

## R3：可维护发布

每个版本只做少量高价值改动：回归测试、冻结构建、许可清单和用户说明一起更新。诊断器、详细报告和高级字段留在开发/报告层，普通用户流程保持简单。

## 暂不承诺

不承诺所有软件和所有笔刷无损互转，不承诺机器学习能自动还原目标引擎，也不承诺没有真实软件/设备条件时的“正式兼容”。这些是长期研究项，不能挤占当前格式质量修复。
