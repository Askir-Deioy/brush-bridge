# CSP 仿 SAI2 取色器 MVP

版本：0.5.9 开发版。

当前是独立悬浮取色器，二维区域使用根据 SAI2 截图反推的 V-HSV 候选模型。它不修改 CSP，也不依赖 CSP 安装路径。

- 色相环和二维饱和度/明度区域支持鼠标拖动；界面采用 CSP/SAI 风格的外圈色环与中央方块嵌套布局，色环方向按习惯排列为左上红/橙、右上绿、下方蓝/紫。顶部仍与 HSV 一致，向下移动时按 V 相关幂变换压低非主色通道，以保留暗部饱和度。
- 二维区域使用 NumPy 向量化渲染并缓存当前尺寸/色相，避免拖动时逐像素 Python 循环造成卡顿。
- RGB、HSV 和 HEX 可相互编辑。
- 支持复制 HEX、窗口置顶、隐藏后从“便捷工具”恢复。
- 同步模式下拉框已经预留“手动同步、自动同步、仅复制 HEX”。

当前只实现独立 V-HSV 取色和复制 HEX。CSP 前景色联动需要先确认目标 CSP 版本可用的插件或脚本接口，再作为独立适配器接入。

目标 CSP 已确认是本机 `D:\CSP\CLIP STUDIO 1.5\CLIP STUDIO PAINT`，文件版本为 4.2.0.0。SAI2 没有公开精确公式；当前模型是截图驱动的可替换候选实现，需继续用 SAI2 实机点位做数值复核。
