# CSP 仿 SAI2 取色器 MVP

版本：0.5.6 开发版。

当前是独立悬浮取色器，使用标准 HSV 作为基准模型。它不修改 CSP，也不依赖 CSP 安装路径。

- 色相环和二维饱和度/明度区域支持鼠标拖动。
- RGB、HSV 和 HEX 可相互编辑。
- 支持复制 HEX、窗口置顶、隐藏后从“便捷工具”恢复。
- 同步模式下拉框已经预留“手动同步、自动同步、仅复制 HEX”。

当前只实现独立取色和复制 HEX。CSP 前景色联动需要先确认目标 CSP 版本可用的插件或脚本接口，再作为独立适配器接入。

目标 CSP 已确认是本机 `D:\CSP\CLIP STUDIO 1.5\CLIP STUDIO PAINT`，文件版本为 4.2.0.0。SAI2 V-HSV 的公开资料没有提供精确公式，当前 MVP 继续把标准 HSV 和未来的 `VHSVModel` 分开。
