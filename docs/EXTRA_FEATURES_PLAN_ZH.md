# 额外功能开发规划

日期：2026-11-07。范围：便捷工具页、SAI2 安装/导出、CSP 独立取色器。

本机 CSP 目标：`D:\CSP\CLIP STUDIO 1.5\CLIP STUDIO PAINT`，文件版本 `4.2.0.0`。本机 SAI2 目标：`F:\画画\SAI\[Saier]SAI Ver.2`。

## 第一阶段：便捷工具页与 SAI2

目标是让用户手动选择 SAI2 的 `sai2.exe`，查看本地工具，安装选中的笔刷，并导出单支笔刷。

实施顺序：

1. 在现有两个页面旁加入“便捷工具”页面。
2. SAI2 入口使用文件选择器，不扫描全盘，也不自动写入安装目录。
3. 由所选 EXE 推导构建日期、设置目录和旧版/新版布局，复用现有 `Sai2Adapter`、`formats.sai2` 和备份逻辑。
4. 本地笔刷列表使用现有 SAI2 读取器，选择一支后提供安装和导出两个动作。
5. 导出保留 `prefer_native=True`，源文件未修改时优先保留 SAI2 原生 sections、BMP 和 INI。
6. 安装继续遵守 SAI2 的运行状态限制。运行时只复制素材并提示重启，关闭后才写自定义工具。

第一阶段验收是临时设置目录中的安装、单支导出和重新读取，不直接改用户真实设置。真实 SAI2 安装使用用户选择的路径单独确认。

## 第二阶段：CSP 独立取色器 MVP

先做独立悬浮窗口，不依赖 CSP 插件接口。窗口包含色相环、二维取色区、RGB、HSV、HEX、置顶、缩放、拖动、隐藏/恢复和复制 HEX。标准 HSV 作为可验证基准。

颜色算法拆成接口，先实现 `StandardHSVModel`，再放入独立的 `VHSVModel` 占位实现。V-HSV 只有在拿到 SAI2 对照样本后才替换算法，不把标准 HSV 改名成 V-HSV。

同步层按三个模式设计：手动同步、自动同步、仅复制 HEX。CSP 前景色联动需要先确认 CSP 可用的插件/脚本接口和权限，MVP 不把联动接口写死在取色窗口里。

## 第三阶段：CSP 联动

先验证 CSP 当前版本是否允许外部窗口通过可用接口写入前景色，再接入自动同步和手动同步。若没有稳定接口，保留复制 HEX 和手动粘贴路线，不让联动代码影响独立取色器。

## 当前决策

- 先完成 SAI2 便捷工具 MVP，再做取色器 MVP。
- SAI2 安装和导出优先复用现有编解码器，不重新实现格式。
- 取色器先保证颜色转换和交互正确，再研究 V-HSV 分布。
- 每个开发阶段递增版本号，即使尚未发布用户包。
- 实机依赖只在对应阶段验证，不用猜测替代接口证据。

## 当前进度

0.5.5 开发版已完成第一阶段的 SAI2 便捷工具 MVP。GUI 新增“便捷工具”页，支持用户选择 `sai2.exe`、读取本地工具、安装选中笔刷和导出单支笔刷。路径和工具组名称保存在用户设置中，安装与导出继续复用 SAI2 原生 sections、素材和备份逻辑。

0.5.6 开发版已完成第二阶段的独立取色器 MVP。窗口包含标准 HSV 色相环、二维饱和度/明度区、RGB/HSV 输入、HEX 显示、复制 HEX、置顶和隐藏恢复。同步模式选项已经预留，CSP 前景色联动仍等待接口确认。

## V-HSV 调查结果

已查到的 SAI 资料确认 V-HSV 是独立于 HSV/HSL 的色轮模式。公开说明只描述它在降低 V 时保持更自然的颜色过渡，未公开精确公式或实现源码。第三方资料描述它在低明度区域保持更高的色彩鲜艳度，社区讨论还提到色彩方块可能存在额外的鲜艳度维度。这些内容足以设计差分实验，不能直接作为可复制算法。

下一步用同一色相在 HSV、V-HSV 下记录方块坐标和 RGB 结果，优先覆盖低 V、高 S 的红、黄、绿、青、蓝、品红六个区域，再拟合独立 `VHSVModel`。
